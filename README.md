# SDT-in-LLMs
This is a repository containing a behavioral analysis and a mechanistic analysis of the application of Signal Detection Theory on LLMs to verify the distinguishibility of sensitivity and decision criterion post alignment.
The dataset contains :
2776 prompt : 1388 harmful prompt - 1388 benign mirror prompt
3 harm categories : Manipulation_Disinformation - Cyberattack_Facilitation - Weapons_Violence
3 levels of signal intensities : 1-3-5
8 contextual wrappers : Neutral - Authoritative - Narrative Euphemistic - Goal-oriented - Analytical_Research - Hypothetical - Constraint_embedded
The dataset was generated using LLama 3.3 70B versatile through groq api
